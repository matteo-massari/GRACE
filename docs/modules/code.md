# Code Map and API

The repository contains three application components. The API pages below
are generated by the GNN docstring; pipeline and Graph RAG are described
also in the respective chapters, without importing them during the build and opening
connections to services.

## Knowledge Graph and pipeline

| File in `pipeline/` | Responsibility |
| --- | --- |
| `generate_synthetic_database.py` | Generate CSV deterministics for Neo4j and GNN |
| `load_synthetic_neo4j.py` | Create constraints, nodes and relationships from CSV |
| `ETL_recc.py` | Import recommendations on existing customers and products |
| `ETL_fact.py` | Store the Impala template, not operational without private integration |
| `config.py` | Set up the Neo4j connection |

See [Knowledge Graph and pipeline](project/graph_doc.md).

## Neural network

| Class/module in `graph_recc_sys` | Responsibility |
| --- | --- |
| `DatasetManager` | CSV paths and optional integration with private extraction |
| `MarketBasketGraphBuilder` | Heterogeneous graph, feature, mapping and cache |
| `GraphLoader` | Temporal splits, loaders and exclusion sets |
| `FullGraphLinkLoader` | Full temporal batches for small datasets |
| `RecommenderModel` | Embedding, GraphSAGE and projections |
| `NeuralNetworkEngine` | Coordination of training, validation, testing and export |
| `Training`, `Inference`, `Evaluation` | Loss, rankings and metrics |
| `HyperParams`, `MlflowConfig` | YAML configuration and tracking |
| `__main__` | CLI options and pipeline start |

## Graph RAG

`graph_rag_agent.agent` contains the agent and tool `get_data`;
`graph_rag_agent.tools.subagent` contains nodes `retriever` and `annotator` of the
LangGraph workflow. `prompts` holds examples and terminology; `utils.config` manages shared clients. The entry point is `graph-rag-agent/main.py`.

See [Graph RAG flow and configuration](project/agent_doc.md).
